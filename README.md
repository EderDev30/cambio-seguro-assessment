# 💱 Currency Converter

Aplicación de conversión de divisas desarrollada con **Nuxt 3**, **Vue 3**, **TypeScript** y **Tailwind CSS**.

---

## 🚀 Requisitos Previos

Asegúrate de tener instalado [Node.js](https://nodejs.org/) (versión 18 o superior) y [pnpm](https://pnpm.io/).

---

## 🛠️ Instrucciones de Ejecución Local

Sigue estos pasos en tu terminal para ejecutar el proyecto en local:

1. Clonar el repositorio

```sh
git clone https://github.com/EderDev30/cambio-seguro-assessment.git
```

2. Ingresar al directorio del proyecto

```sh
cd cambio-seguro-assessment
```

3. Instalar dependencias

```sh
pnpm install
```

4. Iniciar servidor de desarrollo

```sh
pnpm dev
```

Abre tu navegador e ingresa a `http://localhost:3000`.

---

## 📦 Compilación para Producción

```sh
pnpm build
```
